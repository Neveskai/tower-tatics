# Kenney Tower Defense Kit (CC0) — Fase 1

Importados de `kenney_tower-defense-kit/Models/GLB format/` (CC0). Se o kit só tiver OBJ, o script cai para OBJ e remove `map_Kd` (colormap ausente).

```bash
node scripts/import-kenney-phase1.mjs
```
